raftkv: live demo

A sharded key-value store built on a from-scratch implementation of the Raft consensus algorithm. Three nodes each replicate three shards; every shard elects its own leader. Crash a node and watch the surviving nodes elect a new leader, with no data lost.

Source code and design on GitHub

Read and write

Every write is committed by a majority of the shard's replicas before it is acknowledged, so it survives a crash. Try: put a value, crash the node that leads its shard, then get it again.

What just happened

    A public sandbox: data resets when the demo restarts, only one node can be down at a time (so a majority always survives), and a crashed node restarts from its disk after 6 seconds.
